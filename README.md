# 🏠 RentHouse Property Management System

A modern **Property Rental & Management System** developed using **WordPress**, **PHP**, **MySQL**, and a **custom-built WordPress theme**. This project streamlines property listing, tenant management, landlord interactions, advertisements, and payment handling through a clean and responsive web interface.

---

## 🚀 Features

* 🏡 Property Listing & Management
* 🔍 Advanced Property Search & Filtering
* 👤 User Authentication (Login & Registration)
* 🏢 Landlord & Tenant Dashboards
* 💳 Payment Management
* 📢 Advertisement Management
* ❤️ Wishlist / Favorite Properties
* 📍 Property Details with Images
* 📞 Contact & Inquiry Forms
* 📱 Fully Responsive Design
* ⚡ Custom WordPress Theme Development

## ⚙️ Installation

1. Clone this repository

```
git clone https://github.com/Inspiredlk/RentHouse-Property-Management.git
```

2. Copy the project into your XAMPP `htdocs` directory.

3. Start **Apache** and **MySQL** using XAMPP.

4. Import the project database into phpMyAdmin.

5. Update the database credentials in `wp-config.php`.

6. Visit:

```
http://localhost/renthouse
```
